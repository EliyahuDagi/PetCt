What you are looking at
  • Non-corrected input — what the scanner measures without a CT scan. Deep organs read too dim and there is a bright rim at the body surface, because signal from deep inside the body is absorbed on its way out.
  • Prediction — this model's estimate of the corrected image, computed from the non-corrected input alone. No CT scan is used at any point.
  • True corrected — the clinical image produced the standard way, using the patient's CT scan. This is the target. None of these patients were trained on.
  • Difference — prediction minus truth: blue where the prediction is too dim, red where it is too bright, flat grey where the two agree.
Honest caveats about this viewer
  • Every volume is 128×128 in-plane with all native slices kept. That is the grid the model runs on and the grid the report's numbers come from, and it is coarser in-plane than the original scan.
  • Intensities are normalised per patient with a 99th-percentile clip, so 1.0 means that patient's bright level, not an absolute uptake value. Peak lesion intensity cannot be judged from these images.
  • Pixel values are stored here as 256 levels, for display size. No number in the report is computed from this file.
  • The cached volumes do not carry slice spacing, so the coronal and sagittal views are drawn one row per slice. Use depth stretch if you know the real ratio — it changes the display only.
